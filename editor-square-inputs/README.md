# 方形数字输入框 (editor-square-inputs)

数字/文本输入框从圆形变为方形，视觉上更清晰地区分输入区域。

## 安装

在 ExtensionBuilder 的「设置 → 插件管理 → 安装插件」中输入：

```
github:dhdbvcg/scratch-ext-addons
```

或单独安装本目录：选择本地 `index.js` 文件导入。

## 适用积木

`math_number` / `math_integer` / `math_whole_number` / `math_positive_number` / `math_angle` / `note` / `text` / `argument_editor_string_number` / `colour_picker`

## 清理

插件禁用时会还原 `BlockSvg.prototype.jsonInit`。
