# 实时协作 (Real-time Collaboration)

多人实时协作编辑扩展制作器。

## 功能

- **创建/加入房间**：生成随机房间ID或输入已有房间ID加入
- **用户列表**：显示所有在线用户，标记房主和 yourself
- **聊天**：实时文字聊天
- **工作区同步**：Blockly 工作区 XML 实时在所有协作者间同步
- **隐私设置**（房主）：公开房间 / 私人房间
- **URL 分享**：一键复制房间链接（支持 `#rtc=房间ID` 深链接）
- **用户名**：自定义显示名称

## 技术实现

- **WebRTC**（通过 PeerJS 库）点对点连接
- 数据不经过中心服务器（仅信令经过 PeerJS 云服务）
- 房主的工作区状态作为权威源，新加入者自动获取最新 XML

## 使用方式

1. 在 ExtensionBuilder 设置中安装此插件并启用
2. 点击工具栏「🤝 实时协作」按钮打开协作面板
3. 「创建新房间」→ 复制 URL 分享给他人
4. 或「加入房间」→ 输入对方分享的房间 ID
